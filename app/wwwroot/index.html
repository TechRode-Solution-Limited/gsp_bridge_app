🧪 TZ Info (slot configuration)

Read/write raw TZ strings for slot indices 0–50. TZ 1 = all-day (00002359 × 7). A "never" zone is 00000000 × 7 = 56 zeros — click the button to pre-fill. Write the never zone to slot 20, then point a user at it via the TZs test above.

🧪 Update User Group

Read/write the access group a member belongs to (legacy integer API — GetUserGroup / SetUserGroup). Groups are 1-based on this device — group 0 returns -4993 (same as TZ slot 0). Use group 1 as the default/unblocked group. Configure group 2 with a "never" TZ, then flip between group 1 (open) and group 2 (blocked) to non-destructively gate access.

🧪 Group TZ (SSR)

Read/write TZ assignments for access groups 1–9 (SSR API — group 0 is not supported on ZAM180_TFT, returns -4993). Plan: write a "never" TZ to slot 20, set group 2 to tz1=20 tz2=20 tz3=20, then flip users between group 1 (normal access) and group 2 (blocked) using the User Group section above.
